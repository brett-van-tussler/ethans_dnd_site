# Static Assets Directory

This directory contains all static assets for the website. Each type of content has its dedicated subdirectory for better organization.

## Directory Structure

- `/images/` - For all image assets (screenshots, photos, illustrations)
  - `/backgrounds/` - Background images
  - `/icons/` - Icon assets
  - `/hero/` - Hero section images
  - `/blog/` - Blog post images

- `/fonts/` - Custom font files

- `/media/` - Other media files (audio, video, etc.)

- `/documents/` - PDFs, documents, and downloadable content

## Guidelines

1. Always place assets in their appropriate subdirectories
2. Use meaningful names for files (e.g., `hero-banner.jpg` instead of `image1.jpg`)
3. Optimize images before adding them to reduce load times
4. Use appropriate file formats:
   - JPG for photographs
   - PNG for images requiring transparency
   - SVG for icons and logos when possible
   - WebP as a modern alternative when broad browser support isn't required
